# 作り置き冷凍スープの「パキッと割り氷」パズルメーカー

タッパーで固まった冷凍スープや離乳食を、使いたい分量だけストレスなくパキッと折るための保存形状と解凍手順を計算するツール

## 🌟 主な特徴
- **完全フロントエンド完結**: サーバー不要でブラウザを開くだけで即座に動作。
- **安心・安全**: データはブラウザのローカル環境のみで処理され、外部への通信は行いません。
- **モバイル対応**: スマートフォン・PCのどちらでも直感的に使えるレスポンシブ設計。

## 🚀 使い方
1. リポジトリ内の `index.html` をブラウザで開きます（または GitHub Pages でアクセス: https://kam2525-hub.github.io/frozen-soup-break-blocker/）。
2. 画面の指示に従って操作します。
